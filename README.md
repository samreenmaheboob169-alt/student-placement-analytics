
# Student Placement Analytics Dashboard (CSE)

## About the Project
This project analyzes student placement performance using Microsoft Power BI. It provides insights into academic performance, technical skills, internships, certifications, and placement outcomes.

## Objectives
- Analyze student placement rates.
- Calculate the average salary package.
- Compare CGPA with salary packages.
- Analyze the impact of internships and certifications.
- Visualize year-wise placement trends.

## Technologies Used
- Microsoft Power BI
- Microsoft Excel
- DAX
- Power Query

## Dashboard Features
- Total Students
- Students Placed
- Placement Rate
- Average Package
- Average CGPA
- Placement Status Analysis
- Skills and Internship Analysis
- Year-wise Placement Trends
